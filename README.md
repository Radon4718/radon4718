## 💫 About Me

I build AI automation that survives contact with real users — n8n agents, retrieval over your own documents, and the Python services that take over when no-code hits its ceiling.

Game dev is where I learned systems design, and it still is: FSMs, procedural generation, and reinforcement learning agents that learn behaviour instead of following a script.

## 🔭 Currently Working On

AI agents in n8n — support inboxes answered from a vector store, lead qualification mid-conversation, scheduled content pipelines with an audit ledger

**Fish Racer** — a Godot 4 multiplayer runner: infinite threaded procedural terrain, custom host-migration protocol, multi-phase boss FSM

## 💬 I Love Talking About

Agent design — retrieval, memory, and the confidence gate that decides between replying on its own and parking a draft for a human

Backends that hold up — FastAPI with Celery/Redis for jobs too heavy for a request cycle, Spring Boot in production

Procedural and AI-driven behaviour in games

## ⚡ Fun Fact

I trained a reinforcement-learning agent that discovered it could farm stamina rewards by standing perfectly still. Fixing that taught me the thing I use every week now: **an agent does exactly what you incentivised, never what you meant.**
